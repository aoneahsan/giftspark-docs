# Frequently Asked Questions

**Quick answers to the most common questions about GiftSpark.** For deeper detail, follow the links into the feature pages.

## Cost and access

**Is GiftSpark free?**
Yes — the core platform is free to use. Optional card payments use Stripe only if an organization enables them; the rewards economy itself runs on points and needs no money to move.

**Do I need to install anything?**
No. GiftSpark runs in the browser at [giftspark.aoneahsan.com](https://giftspark.aoneahsan.com). You can also install the [Android app](apps/mobile-app.md) for push notifications and biometric unlock.

## Sign-in and accounts

**How do I sign in?**
With Google. There's no separate password. On mobile, native Google sign-in bridges into the same account you use on the web.

**Can I belong to more than one organization?**
Yes. A single account can join multiple organizations and switch between them.

## Platforms

**Where does GiftSpark run?**
A React web app, native Android and iOS apps (built with Capacitor), and a companion [browser extension](apps/browser-extension.md) for saving gift ideas.

**Is my data the same across devices?**
Yes — everything syncs through a shared Firebase backend, so recognition, points, and rewards are consistent everywhere you sign in.

## How it works

**How does recognition become a reward?**
Giving and receiving recognition earns points; points are redeemed in the [Regalos rewards catalog](features/regalos-and-rewards.md) through an approval and order workflow.

**Who can see my recognition?**
Recognition is posted to the organization feed by design — public visibility is what makes peer recognition effective. Private profile fields stay private unless you share them.

## Data and privacy

**What data does GiftSpark collect?**
Account basics (name, email) for functionality, and app-interaction and device data for analytics. Data is encrypted in transit. See the [privacy page](legal/privacy.md) for the full picture and how to delete your data.

**Is my data sold?**
No. Operational services (analytics, error tracking, chat delivery, maps, push) process data to run and improve the product, as described in the privacy page.
