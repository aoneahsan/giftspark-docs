# Mobile App

**GiftSpark ships native Android and iOS apps built with Capacitor, giving you the full platform plus push notifications, biometric unlock, and native Google sign-in.** Recognition works best when it's one tap away, and the mobile app keeps the feed, rewards, and events in your pocket.

## Installing

- **Android** — install from [Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.giftspark).
- **iOS** — the iOS app is built with the same Capacitor codebase.

You sign in with the same Google account you use on the web, and everything syncs through the shared Firebase backend.

## Native capabilities

The mobile app adds device features on top of the web experience:

- **Push notifications** — recognition, reminders, and updates arrive as native notifications (powered by OneSignal).
- **Biometric unlock** — protect access with fingerprint or face unlock on supported devices.
- **Native sign-in** — Google sign-in uses the device's native flow and bridges into the same account.
- **Sharing and haptics** — native share sheets and tactile feedback make interactions feel at home on the platform.

## Edge-to-edge display

The Android app renders edge-to-edge on modern Android versions, with the system bars handled so content sits correctly in the safe area and the bars match the app's theme in both light and dark mode.

## Use cases

- **In-the-moment recognition** — thank a teammate right after a meeting, from your phone.
- **Never miss an event** — push reminders surface birthdays and milestones in time to act.
- **Secure quick access** — biometric unlock keeps your account protected without retyping anything.
- **Same data, anywhere** — start on the web and pick up on mobile seamlessly.

## Frequently asked questions

**Do I need a separate account for mobile?**
No. Sign in with the same Google account; your data is shared across web and mobile.

**Is the mobile app free?**
Yes — the app is free to use, like the web platform.

**Which platforms are supported?**
Android (on Google Play) and iOS, both from the same Capacitor codebase, alongside the web app.
