# Changelog

Notable GiftSpark releases, latest first. This mirrors the in-app and store release notes so there's a single, consistent record of what shipped.

## v0.2.0 — June 2026

- Social recognition feed — give and receive kudos and thank-yous
- Leaderboards and rankings
- Badges and achievements
- Employee directory with searchable profiles
- Pulse surveys for team feedback
- Regalos rewards catalog
- Daily engagement streaks
- Engagement health scores
- Team and personal goals
- Biometric security (Face ID / fingerprint) on mobile
- Dark mode support
- Accessible design aligned to WCAG 2.1 AA

## Earlier

The 0.1.x line established the foundation: Google sign-in, organizations with role-based access, the recognition feed, the Regalos rewards module, and the Capacitor mobile shell for Android and iOS.
