# Regalos & Rewards

**Regalos is GiftSpark's rewards module — the catalog where members redeem the points they earn for real items, routed through categories, approvals, redemption codes, a cart, and order history.** ("Regalo" means "gift.") It closes the recognition loop: the points you earn from peers become something tangible.

## The rewards catalog

The catalog is organized into **categories** so members can browse by type. Each item shows its point cost and details. Admins manage the catalog — adding items, setting costs, and organizing categories — from the admin area.

## Redeeming points

When a member redeems an item:

1. They add it to their **cart** and submit a redemption.
2. Depending on the organization's settings, it is fulfilled immediately or sent for **approval**.
3. On approval, the redemption is recorded and the member can track it under **Orders**.

## Approvals

Some rewards warrant a review step. GiftSpark supports **approval requests** so an admin or manager can confirm a redemption before it's fulfilled. This keeps the rewards economy under control and gives admins a record of what's being redeemed.

## Redemption codes

For certain rewards, GiftSpark issues **redemption codes** that a member can use to claim the item. Codes give you a clean way to distribute digital rewards without manual handoff.

## Orders

Every redemption produces an order with a status the member can follow. The order history is the member's record of what they've claimed and where each request stands.

## Payments

Most of the rewards flow runs on points and needs no money to move. When an organization wants to support card payments for paid items, GiftSpark integrates **Stripe**; when Stripe isn't configured, the flow falls back to an admin-managed mode so the catalog still works. You're never required to set up payments to use rewards.

## Use cases

- **Points to product** — a member spends a quarter's recognition points on an item from the catalog.
- **Controlled high-value rewards** — an admin requires approval for the most expensive items.
- **Digital rewards at scale** — a redemption code delivers a digital reward instantly.
- **Tracking spend** — an admin reviews orders to see what the team values most.

## Frequently asked questions

**Do I need money to use rewards?**
No. The core flow runs on points. Card payments via Stripe are optional and only used if your organization enables them.

**Who manages the catalog?**
Admins manage items, categories, and costs from the admin area.

**Can redemptions require approval?**
Yes — approval requests let admins or managers confirm a redemption before fulfillment.

**Where do I track a redemption?**
Under **Orders**, where each redemption shows its current status.
