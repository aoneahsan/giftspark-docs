## About GiftSpark

GiftSpark is an employee engagement platform combining peer recognition, a rewards catalog (Regalos), pulse surveys, gamification, and team gifting across the web, native Android and iOS (via Capacitor), and a companion browser extension. It is built on a modern stack — React 19, TypeScript, Vite, Radix UI, TanStack Router, Zustand, and Firebase — with analytics and reliability tooling layered in.
