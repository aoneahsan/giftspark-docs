# Setup & Roles

**This guide is for the person setting up a GiftSpark organization — creating it, assigning roles, and configuring the rewards economy.** GiftSpark supports multiple organizations with role-based access, so each company, department, or team runs its own independent space.

## Creating an organization

After [signing in](../getting-started/account-setup.md), choose **Create organization** and name it. You become its owner. From there you can invite members, build the rewards catalog, and configure how recognition and rewards work for your team.

## Roles and permissions

GiftSpark uses role-based access control. The common roles are:

| Role | Can do |
|---|---|
| **Member** | Give and receive recognition, redeem rewards, join gifting and events. |
| **Manager** | Everything a member can, plus the manager dashboard and team insights. |
| **Admin / Owner** | Configure the organization, manage the catalog and budget, approve redemptions, manage roles. |

Permissions are granular behind these roles, so admins control who can administer the catalog, approve redemptions, manage members, and view insights.

## Configuring rewards and budget

As an admin you'll typically:

1. **Build the catalog** — add reward items, set point costs, and organize categories in the [Regalos](../features/regalos-and-rewards.md) module.
2. **Set the budget** — define recognition and rewards budgets and track usage with the [budget planner](../features/budgets-and-finance.md).
3. **Decide on approvals** — choose which redemptions need an approval step.

## Managing members

Invite teammates, assign their roles, and organize them into teams and subgroups. The full flow is in [Members & teams](members-and-teams.md).

## Use cases

- **Company-wide rollout** — an admin sets up one organization for the whole company and delegates manager roles per department.
- **Department pilot** — a single team runs its own organization to trial GiftSpark before a wider rollout.
- **Controlled rewards** — an admin requires approval for high-value redemptions and tracks spend against budget.

## Frequently asked questions

**Can one person belong to multiple organizations?**
Yes. A single account can join more than one organization and switch between them.

**Who can change roles?**
Admins and owners manage roles within their organization.

**Do I need to configure payments to launch?**
No. The rewards economy runs on points; card payments are optional and added only if you want them.
