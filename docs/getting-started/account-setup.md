# Account Setup

**This guide takes you from no account to a complete GiftSpark profile inside an organization.** It covers signing in, joining or creating an organization, and filling in the profile details that make recognition and gifting work well.

## 1. Sign in

GiftSpark uses Google sign-in. There is no separate username or password to remember.

1. Open [giftspark.aoneahsan.com](https://giftspark.aoneahsan.com) (or launch the mobile app).
2. Choose **Continue with Google**.
3. Pick the Google account you want associated with GiftSpark.

On the web, sign-in uses a Google popup. On the native Android/iOS app, it uses the device's native Google sign-in and bridges the result into the same account — so you land as the same user regardless of platform.

## 2. Join or create an organization

After signing in, you either join an existing organization or start your own.

- **Have an invite?** Open the invite link or enter the code you were given. You'll be added to that organization with the role the admin assigned.
- **Starting fresh?** Choose **Create organization**, give it a name, and you become its owner. You can then invite teammates from [Members & teams](../organization/members-and-teams.md).

A single account can belong to more than one organization and switch between them.

## 3. Complete your profile

A complete profile improves recognition, gifting, and event reminders:

- **Name and photo** — how you appear in the feed, directory, and leaderboards.
- **Important dates** — your birthday and work anniversary power event reminders for teammates (you control visibility).
- **Interests and style** — optional signals that improve gift recommendations and the AI gift finder.

## 4. Set your preferences

From **Settings** you can configure:

- **Notifications** — choose what you're notified about, and enable push on mobile.
- **Theme** — light, dark, or follow the system setting.
- **Privacy** — control which profile fields are visible to your organization.

## Troubleshooting

| Symptom | Fix |
|---|---|
| Google popup is blocked on web | Allow popups for the site, or use the redirect prompt the app falls back to. |
| Invite link says expired | Ask your admin to re-send it; invites can be time-limited. |
| Signed in but see no organization | You haven't joined one yet — create one or request an invite. |

Once you're in, head to the [Quick Start](quick-start.md) to send your first recognition.
